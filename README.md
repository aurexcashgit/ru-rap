# ru-rap

Агент-скилл для написания русского рэпа **под конкретный бит**. Снимает ритм-сетку с аудиофайла,
выводит слоговый коридор строки, пишет текст в этот коридор и проверяет укладку скриптом.

> Agent skill for writing Russian-language rap to a specific beat: extracts the real rhythmic grid
> from an audio file (BPM, grid phase, kick/clap/hat pattern per 16th, half-time vs backbeat,
> straight vs triplet), derives the syllable corridor for one line, and validates the written lines
> against it. Russian phonetics and syllable length — existing lyric skills assume English or Mandarin.

## Зачем

Текст в этом жанре пишется не «красивыми фразами», а под сетку: сколько слогов влезает в такт —
первый параметр, всё остальное после. Почти все неудачные парты звучат одинаково — строки гуляют
по длине, рифма падает мимо удара, панчи идут по одной схеме. Скилл закрывает все три пункта
измерением, а не на слух.

Отдельная причина существования: русский слог длиннее английского, и калька с английского флоу
не работает. Там, где в английском помещается 16 коротких слогов, в русском 12–13.

## Установка

```bash
git clone https://github.com/aurexcashgit/ru-rap.git ~/.claude/skills/ru-rap
```

Требуется `ffmpeg` в PATH и `numpy`. Скилл подхватывается автоматически, вызывается по смыслу
запроса («напиши парт на этот бит») или напрямую через `/ru-rap`.

## Скрипты

### beat_grid.py — снять сетку с бита

```bash
python3 scripts/beat_grid.py бит.mp3 --from 13.7 --lines 16
```

```
BPM             140.00
фаза сетки      0.017с
такт            1.714с
дроп            ~20.0с
хэты            ровные 16-е  (16-е 1.33 / триоли 0.61)
доля            ХАВ-ТАЙМ, строка в два такта  (BPM выше 118)

паттерн по 16-м (0 нет / 9 макс)
              1   e   &   a   2   e   &   a   3   e   &   a   4   e   &   a
  КИК         9   1   2   1   4   5   3   3   4   0   2   2   4   5   4   4
  КЛАП        8   8   3   1   6   5   5   0   7   0   7   3   9   3   9   4
  ХЭТ         7   0   3   2   3   0   5   0   7   0   9   2   7   0   7   2

СТРОКА = 2 такт(а) = 3.43с = 16 восьмых
удар голосом в слоты: 1, 5, 9, 13
слоговый коридор: 11–14 слогов на строку
```

Плюс таймкоды всех строк от секунды захода. Первая доля такта определяется по максимуму низа —
иначе сетка цепляется за снейр и бит ошибочно читается как хав-тайм.

### fit_lines.py — проверить укладку строк

```bash
python3 scripts/fit_lines.py строки.txt --slots 16 --accents 1,5,9,13
```

```
 4. [ok     ] 14 сл  мой первый лям был чужой, я закрыл его молчком
            МОЙ-пер-вый-лям | БЫЛ-чу-жой-я | ЗАК-рыл-е-го | МОЛЧ-ком-·-·
13. [ok     ] 14 сл  третьи сутки на ногах, у меня глаза в крови
            ТРЕТЬ-и-сут-ки | НА-но-гах-у | МЕ-ня-гла-за | ВКРО-ви-·-·
            ~ слот 5 (удар) держит предлог «на» — лучше переставить

рифмовка двустиший:
   3/ 4  точная
   5/ 6  ассонанс
   1/ 2  НЕТ РИФМЫ  <-- починить
```

Ловит провис и перегруз по слогам, предлог на сильной доле, рифму, повисшую далеко от удара,
и качество рифмы в двустишии — от точной через хорошую и ассонанс до полного её отсутствия.
